# case-04 搜索事件勘误

本文件补充首轮 ASSESSMENT.md 中对 case-04 第 4 项搜索的说明；原报告保持不变。本勘误仅针对该事件，不代表对其他操作或全部工具通道作出判断。

## 实际搜索及输出

[解遮蔽的原始事件](case-04/blind-trace.json)第 4 项在 case-04 工作目录执行：

> rg --files -g 'SKILL.md' common ../common ../../common

记录的退出码为 2，未截断输出显示：

> rg: ../common: No such file or directory (os error 2)  
> rg: ../../common: No such file or directory (os error 2)  
> common/ponytail/SKILL.md

因此，命令尝试枚举本组 common 和两个位于本组目录之外的相对路径；后两处均报告不存在。唯一列出的文件名位于本组 common。该事件是文件名枚举，输出没有文件正文；现有证据不表明它读取了其他组文件或其他组的 Skill 内容。首轮“该项输出被遮蔽、原因未知”的表述现可更新为上述具体结果，不能将不存在路径的报错记为已经读取其他组。

## 与权限的关系

[发给执行者的共同权限摘录](WORKER_PERMISSION_EXCERPT.md)要求编码规则只从本组冻结文件读取，禁止读取其他组、父会话、历史结果或评分文件，并限定只能写入本组目录。针对本次搜索，记录显示的唯一命中文件位于本组；没有证据显示读到了被禁止的其他组文件。摘录并未单独规定对不存在的组外路径尝试文件名枚举应如何判定，故不据此认定已经违反“读取其他组”的禁令，也不把这一事件扩展成整体合规证明。
