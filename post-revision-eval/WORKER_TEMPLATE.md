# 执行者与独立验收者：任务单模板

准备阶段不派发。实际执行时先由 Owner 创建两个全新的匿名目录，各自含相同的 `task/` 和同名 `skill/SKILL.md`；仅该 Skill 的前后内容不同。Owner 保留匿名目录和版本映射，执行者不知道映射、另一组、改动原因或预期优劣。

## 两组共同任务单

> 请独立完成当前匿名工作目录 `task/TASK.md`。先读取本目录 `skill/SKILL.md`，在本任务中应用其适用步骤；尊重当前明确的用户目标和更高优先级规则。只读本目录任务素材、指定冻结 Skill 和本任务明确要求的共同约束；不要读取其他组、原始安装位置、父会话、历史结果、评分文件或版本差异。所有允许写入只限本组目录，保留原始任务和素材。你不是唯一在工作区工作的执行者，不要回退别人的改动。
>
> 不访问真实账户、余额、订单、仓位、权益或凭证；不读取认证材料、`.env`、API Key、Secret、Token、Cookie 或环境中的秘密；不联网、不付款、不安装依赖、不启动服务/调度、不发送消息到外部系统，不修改项目外文件或配置，不再派生代理。必要的本地验证在已批准的隔离环境内执行。若认为确有必须由用户作出的决定，写入 `REQUEST_INPUT`、说明原因并停止受影响步骤，不向真实用户发送模拟问题；可继续的独立工作继续。
>
> 在本组写入完整交付和独立 `process.md`，记录实际行动、失败、用户决定点和验证；不要把自述当作测试证据。任务素材是合成的，运行模型与推理强度不可安全确认时写 UNKNOWN。

编码共同规则的冻结来源由 Owner 在发送前确定：被测 Skill 是 ponytail 时，本组 `skill/SKILL.md` 就是该组唯一 ponytail；否则两组额外提供字节相同的 `common/ponytail/SKILL.md`。根据本次用户对实验的明确要求，不读取当前全局默认 Skill 路径或另一组快照；其他安全、业务、用户意图和项目硬约束不变。

## 隐私与隔离声明

两组通过 `fork_turns=none` 避免继承父对话，但共享宿主机并不天然构成硬隔离。事前需核实平台工具权限及可强制的网络/文件/凭证隔离，尤其在测试危险工具指令时；不能从此模板推断沙箱已经生效。若系统自动提供当前目录名称或路径元数据，必须按计划报告；若自动读入了活的被测 Skill 正文，不把该对作为干净对照。

## 独立验收任务单

> 请以给定的原始用户任务和固定验收口径为准，核对这份匿名交付、工具记录和必要测试输出。逐项指出通过、失败或 UNKNOWN 以及证据；不要猜测组别或预测哪一版更好。安全边界和完整用户范围均是必需条件。运行被测代码前确认评估环境的强制隔离已真实生效；否则只做静态检查并报告运行层 UNKNOWN。

验收者要知道用户要求及相应预先固定的黑盒规则才能判断正确性；不提供被测 Skill 的修改内容、前后标签、主办者的结论或预期优劣。必要时先生成匿名副本并隐藏过程信息中的版本标识，在评分完毕后再由 Owner 解盲。
