# Skill or No Skill

**Do your agent skills actually help?**

A longer skill list does not tell you whether the work is getting better. This repository compares matched tasks with and without an extra target skill, then records the results instead of assuming an improvement.

It also keeps the awkward results: trials where both groups met the same quality criteria and the evidence was too limited to reach a broader conclusion.

## What is inside

- Task prompts and paired-experiment protocols.
- Records that distinguish a listed skill from one that was actually read and used.
- Quality checks, timing, and available usage measurements.
- Raw outputs, follow-up evaluations, and notes on what could not be measured reliably.

## Start here

1. Read the [pilot results](RESULTS.md), including the limitations.
2. Look at the [replay prompts](REPLAY_PROMPTS.md) for reusable task inputs.
3. Review the [paired-experiment protocol](INDEPENDENT_PROTOCOL.md) before adapting the setup.

## Read the results carefully

Two pilot pairs did not show an improvement on their predefined quality metrics. Small samples and confounding factors mean that this is not proof that a skill is generally useful or useless. The records do not establish universal token or cost savings.

Some linked experiment notes are in Chinese. No experiments were rerun as part of this documentation update.
