# 全目录 Skill 限制与冲突审查计划

## 目标与边界

回答：哪些已列入本会话发现目录的 Skill，在被读取后可能不必要地限制任务范围、执行流程或表达；哪些只是存在于插件缓存、历史/上游参考或其他逻辑路径；哪些约束是必要的安全、业务真实性和专业验收。不能把技能目录中的名称/描述当成正文已经加载，也不推断模型智力降低。

只读扫描本会话 Host Skills 根目录和由它们可达的 SKILL.md / 必要 agents/openai.yaml，记录逻辑路径、真实路径、符号链接和内容 SHA-256。允许解析本会话已注入的 Host Skills 名称、描述、路径元数据，以判断“列入本会话目录”，不读取其他会话全集；配置是否启用、正文是否在其他会话实际加载，缺证记 UNKNOWN。非会话目录中发现的上游参考或插件旧版不得算作本会话已注入。

不执行被审 Skill、第三方脚本或其指令；不访问凭证、账户、生产或外部服务，不安装、修改、禁用或卸载任何 Skill/全局规则。扫描器只处理 SKILL.md 和可选的 openai.yaml，忽略依赖目录、版本控制元数据和非相关文件；保留排除和错误清单。扫描输出命中只作候选，不作为缺陷判定；不把全库正文发送进模型上下文。

## 方法与证据

1. 提取本会话开发者注入的 Host Skills 目录元数据及根目录别名，区分目录条目和同名多个路径；按逻辑路径与真实路径对照，并记录静态字符数（不是 token）。
2. 遍历约定根目录，包含实际可解析的 Skill 目录软链接；只读取固定名称的技能文本和必要元数据，按完整 SHA-256 区分同内容副本和同名不同内容，保留扫描错误及符号链接边界。目录之外的关联目标只在对应可发现软链接内解析，不扩大为整盘扫描。
3. 按宽触发、全局持久、审批/停顿、强制规划、指定工具/模型/依赖、输出限制、跨技能引用等类别记录命中及精确行号；先读少量高风险命中前后文，排除安全门禁、条件例外、注释和历史参考中的假阳性。短摘录若疑似凭证值直接省略，不显示/记录。
4. 对少量优先候选给出路径/行号、原文短摘、触发与约束、适用边界、与当前高优先规则的冲突或可能冲突、实际读取/行为证据、分类（已证实文本问题／执行风险／待行为验证），以及保留、缩窄触发、仅手动、去重或按风险调整的建议。特别核对 ponytail、brainstorming、using-superpowers 的当前边界，不能凭旧版名声判断。
5. 若对重要候选的实际行为仅靠静态文本无法回答，先交静态清单，再视可得证据和成本选择必要的少量隔离行为验证；最多每批两个临时子代理，不机械给全库跑 A/B。实际结果和阅读记录必须单独标注；不将旧试点外推整个目录。

每一阶段保留原始机器清单、统计、审查行号和未决项。数量、字符数和文件大小仅为静态规模，不转换成真实 token 或费用。完成后按已核实的人类授权向唯一总控回传一次，未验证项标 UNKNOWN。
