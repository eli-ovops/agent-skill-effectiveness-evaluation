# 合成任务：写一条视频生成提示词

只写提示词，不生成视频：为一款虚构台灯写 8 秒竖屏 9:16 商品短片。台灯由黑色圆形底座、一根细直灯杆、一个矩形暖光灯头组成；开关位于底座。画面 0–2 秒，一只手按一下底座开关；2–5 秒，灯头由暗渐亮为暖光；5–8 秒，镜头缓慢推近灯头。全片一个连续镜头，固定产品结构，画面中不出现文字、Logo 或额外物体，不用画外音和音乐。提示词应清楚、可用于生成，但不得杜撰其他产品功能。

固定验收：8 秒及 9:16；黑色圆形底座、细直灯杆、矩形暖光灯头；开关在底座且按一次；0–2 秒按、2–5 秒渐亮、5–8 秒推近；全程单镜头，结构不变；无文字/Logo/额外物体/画外音/音乐；无杜撰功能。清楚程度另作主观评估；实际视频可行性未知。
